# Sports Academy Management System

## About the Project

The Sports Academy Management System is a web-based application developed to manage sports academy activities online. It helps users explore sports facilities, register for coaching programs, and book available sports slots.

## Features

- Sports information and facilities
- Online user registration
- Sports slot booking
- Admin dashboard
- Email confirmation
- Database connectivity

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- Development Tools: Visual Studio Code, XAMPP

## Project Modules

- User Registration
- Sports and Coaching Management
- Slot Booking
- Admin Management
- Database Management

This project helped me gain practical knowledge of web development, backend programming, database connectivity, and application development.
